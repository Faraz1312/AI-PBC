I. ARCHITECTURAL CORE & INITIALIZATION
SYSTEM INITIALIZATION

Auto-start on Raspberry Pi boot via crontab.

Run startup script to initialize microphone and speaker.

Load Modular Core: Python loads all modular scripts (core_llm.py, core_speech.py, core_state.py, etc.) into the runtime environment.

PERSISTENT STATE MANAGEMENT (New)

Load User State: core_state.py loads the user_state.json file to retrieve the last saved lesson and index.

Memory Greeting: Based on the loaded state, the system provides a personalized welcome: "Welcome back! Say 'continue' to resume." (If no state, loads standard greeting).

SPEECH I/O ENGINE

Input (STT): core_speech.py captures voice commands via USB microphone and converts speech to text using Microsoft Azure STT.

Output (TTS): core_speech.py converts all text output to optimized audio using Azure TTS (en-IN-AaravNeural voice).

II. INTELLIGENT ROUTING (THE AI BRAIN)
AI INTENT ROUTING (The V2.1.0 Brain)

The transcribed user text is immediately sent to the core_llm.py module.

Intent Classification: The system uses GPT-3.5 (with zero temperature) to classify the natural language query into a structured JSON object (intent and slot).

Direct Dispatch: The main.py router uses the classified intent and slot to bypass the main menu and call the correct feature_module instantly.

Example: User says "Read my Solar System note" → Intent: notes_read, Slot: "solar system." → Directly calls run_notes_module("solar system").

III. FEATURE MODULES
LEARN MODE (Interactive Lessons)

Resume Feature: Accepts a start_index parameter to resume lessons from the saved index (Persistent Memory).

Reads content from local .txt files in 2-line blocks, pausing for commands.

State Saving: Automatically updates user_state.json every time the user advances or retreats (next, go back).

Explain More: On command, sends text to GPT-3.5 for an expanded, detailed explanation.

DOUBTS/MENTOR MODE

Allows open-ended student questions.

Sends queries to GPT-3.5 for context-aware answers.

TALK MODE (Casual Conversation)

Engages in general, friendly conversation using GPT-3.5.

TESTS MODE (Verbal Testing)

Loads chapter-wise test files and captures spoken answers.

Compares responses to answer keys for scoring and provides instant verbal feedback.

AUDIO NOTES MODE

Supports direct note retrieval using the AI router's notes_read intent.

Allows recording, transcribing (Azure STT), and saving personal notes as text files.

PERFORMANCE REPORTING

Calculates total score and generates a .txt performance report.

Sends report via email to the registered guardian using the Gmail API.

IV. SYSTEM MAINTENANCE
MODULAR CODE STRUCTURE

Code is maintained in three layers: Core (I/O, LLM, State), Features (Lesson, Notes, etc.), and the Router (main.py), ensuring high maintainability and scalability.

OFFLINE-FIRST OPERATION

Note: This version uses stable cloud services. The modular structure (with separate core_llm.py and core_speech.py) is designed to allow for easy replacement with Vosk and TinyLlama modules for offline capability in a future update.

SYSTEM SHUTDOWN FUNCTION

Uses a hardware push button to initiate a safe shutdown sequence.

Prevents file corruption and ensures battery protection via UPS HAT.
